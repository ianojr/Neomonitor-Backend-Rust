# NeoMonitor

A real-time hardware and performance monitor for Windows, written in Rust as a
terminal UI (TUI).

NeoMonitor samples CPU, memory, disk, network and GPU activity, renders them on a
responsive dashboard with live graphs, provides a searchable process explorer, and
runs a lightweight rules engine that surfaces sustained performance problems as
read-only findings with evidence.

## Features

- **Dashboard** — CPU (global + per-core), memory, disk throughput and capacity,
  network and GPU utilisation/memory, with availability-aware gauges
  (a value is never faked: unmeasurable shows `n/a`, held shows `(stale)`).
- **Graphs** — time-series sparklines for the headline metrics.
- **Process explorer** — sortable/filterable, tree view, on-demand details,
  guarded termination (explicit + confirmed; force-only on Windows).
- **Performance investigator** — six rules (CPU, memory, process hog, network
  surge, disk capacity, thermal) with sustained-spike detection, confidence and
  evidence. It is purely informational: it never kills or reconfigures anything.
- **Capability engine** — detects what the machine can actually measure and says so
  honestly (e.g. GPU temperature needs LibreHardwareMonitor; fan/power are `no`).
- **Multi-adapter GPU** — DXGI + PDH, with vendor/type classification.
- **Profile presets** — fast / balanced / eco / minimal sampling cadences.
- **App icon + version metadata** embedded into the executable.

## Requirements

- Windows 10/11, x86_64.
- Rust 1.85+ (edition 2024); builds with the MSVC toolchain.
- For the embedded icon, the Windows SDK (`rc.exe`) — the build warns and
  continues without an icon if it is missing.

## Build & run

```powershell
cargo build --release
.\target\release\neomonitor.exe
```

Useful flags:

```powershell
cargo run --release -- --probe   # raw sources + capability ceiling
cargo run --release -- --bench   # per-source latency + sampler health
cargo run --release -- --help    # key bindings
```

## Keys

| Key | Action |
|-----|--------|
| `g` | cycle view: Dashboard → Graphs → Investigation |
| `i` | jump to the investigation view |
| `s` / `f` / `v` | sort / filter / tree (process table, dashboard only) |
| `/` | search processes |
| `Enter` / `Space` | process details / expand tree node |
| `x` | terminate selected process (asks first) |
| `t` | cycle sampling preset |
| `d` / `[` / `]` | (investigation) toggle rule / adjust threshold |
| `?` | help |
| `q` / `Esc` | quit |
